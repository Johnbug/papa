# PAPA 发布检查

本轮覆盖文案、中文/英文/日文、上传流程、游戏交互、隐私说明、无障碍标签和依赖安全。代码检查与真实设备检查是不同的验证，未做的项目不能当作已通过。

## 已完成的产品调整

- 默认蜜桃，主动切换内置成年虚构人物图，然后选择自己的图片。
- 全部 107 个界面、编辑器、错误和无障碍文案提供中文、英文、日文；英日标题与按钮按紧凑布局缩短。
- 语言优先级：网址 `?lang=zh|en|ja` → 用户保存的选择 → 浏览器语言 → 英语。手动切换会更新网址、页面语言、标题和描述，不清空当前游戏。
- 去掉品牌旁未经确认的注册商标符号。内置人物明确为虚构成人，图片上传说明明确限于当前浏览器。
- 页脚增加隐私与使用说明，以及访问/操作统计开关。关闭后阻止后续应用自定义事件及 SDK 的页面/自定义事件上报；不能撤回已发送的数据。偏好可跨标签页同步，存储不可用时仍在本页生效。
- 修复软糯度滑块的读屏名称。纯触屏设备不加载隐藏的手型光标，减少约 1.1 MB 图片下载。

## 安全依赖更新

React / React DOM / RSC 统一升级至 19.2.8，Vite 更新至 8.0.16，Vinext 更新至 beta.6，配套 RSC 插件更新至 0.5.34。备用 Cloudflare 工具链通过限定到父依赖的 overrides 使用修复版 esbuild、undici、ws 与 sharp。保留现有主要版本和两套部署脚本，两种构建已验证通过。后续上游解除旧版本固定后，可移除这些 overrides 并重新审计。

## 发布验收状态

1. **正式网址（已完成 HTTP 验收）**：[papa.bugmaker.info](https://papa.bugmaker.info/) 公开返回 200；HTTP 返回 308 并跳转 HTTPS，已配置 HSTS。线上 JS/CSS 文件名与本轮构建一致，脚本包含三语、隐私开关及打点代码。英文/日文链接、内置图片、图标和 Vercel 统计脚本均返回 200。此项不等于浏览器交互验收。
2. **真实手机**：用 iPhone Safari 与 Android Chrome 各走一遍三种语言、短按、长按/拖动、首次播放声音、上传、裁剪、选区、应用、重新调整、取消和返回蜜桃。尤其检查 320–390px 窄屏、日文换行、文件选择器与页面滚动。
3. **真实统计**：在 Vercel Web Analytics 的事件面板确认拍打、图片切换、上传开始和成功应用等事件收到。自定义事件需要 Pro 或 Enterprise。检查隐私开关关闭后不再产生新上报，并排除广告拦截造成的缺失。
4. **键盘与读屏**：Tab 可到达语言、玩具、软糯度、上传和隐私入口；Space/Enter 拍打；编辑器关闭后焦点回到合理位置，滑块名称正确。
5. **面向公众的资料**：正式域名已确定，仍建议补充可用的反馈渠道。当前游戏不需要账号、后端存储或支付系统；无需为首发增加这些功能。

## 可在首发后继续优化

- 蜜桃 PNG 约 1.6 MB，内置人物图约 1.4 MB。保留原图，另做较小的现代图片格式版本后对比效果，可改善弱网加载；本轮未重绘或压缩素材。正式站蜜桃图片为 1,705,549 字节；本次检查连接完整下载约 7.95 秒（首字节约 3.15 秒），仅代表当前检查网络，不能视为所有用户的加载速度。
- 当前语言在客户端选择，三语分享链接可用；不同语言的独立搜索引擎落地页和服务端元信息尚未配置。如果需要国际搜索流量，再增加预渲染语言页面与正式域名的 canonical / hreflang。
- 如需要公开传播卡片，再单独设计社交分享图；本轮没有自动生成素材。

## 验证边界

本轮已通过类型检查、27 项单元测试、Vercel 与 Vinext 两种生产构建、新增模块静态检查及代码复核。完整依赖审计与生产依赖审计均报告 0 个已知漏洞；这不代表不存在未知漏洞。三个语言链接和客户端模块、本地图片资源均通过 HTTP 检查。未执行浏览器截图或真实设备操作测试；正式站已完成上述 HTTP/资源核验；真实设备、浏览器交互以及统计面板入账仍需核验。
